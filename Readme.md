# 2D Tag Minigame (Pygame)

A two-player 2D platformer tag game created with Python and Pygame. 
One player controls the wolf, while the other controls the sheep trying to evade capture across various platforms.

## Features
- Local 2-player mechanics (Wolf vs. Sheep)
- Basic physics and collision detection (jump pads, platforms)
- Timer and win condition logic
